# Аким на 5 часов

Streamlit-симулятор управления районами Астаны. Выберите пять городских инициатив, распределите их по районам и оцените влияние на Astana Quality of Life Score.

## Запуск

Требуется Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В VS Code можно выбрать интерпретатор `.venv\Scripts\python.exe` и запустить конфигурацию **Run Akim Streamlit app** клавишей F5.

## Советник GPT-4o (необязательно)

Для текстового анализа сценария задайте переменную окружения `OPENAI_API_KEY`. Без неё симулятор и расчёт Score продолжают работать, а в блоке советника отображается подсказка.

```powershell
$env:OPENAI_API_KEY = "ваш-ключ"
python -m streamlit run app.py
```

Не добавляйте ключ в исходный код или репозиторий.

## Игровые правила

- Виртуальный бюджет: 100 единиц.
- Нужно выбрать ровно пять уникальных мероприятий.
- На одно направление можно взять не более двух мер.
- Для районных мероприятий укажите район; городские мероприятия действуют во всех районах.
- Сроки, эффекты, синергии, несовместимости и формула оценки заданы в `calculator.py`.

Итоговый балл рассчитывается кодом. GPT-4o используется только для объяснения результата.
